# 홍대플로우 디자인 시스템

실제 목업(`홍대플로우 모바일 목업`)에서 쓰는 값을 기록한다. 값이나 사용처를 바꿀 때 코드와 이 문서를 함께 고친다.
원칙: [디자인 원칙](https://github.com/sngmng6506/Oh-My-System/blob/main/DESIGN_PRINCIPLES.md)

## 기준

- 모바일 우선, 화면 폭 390px 기준. 넓은 화면에서는 목록을 2~3열로 늘린다.
- 본문은 쉬운 말로 쓴다. 전문 용어 대신 "서서 보는 공연", "처음 가기 좋음"처럼 쓴다.
- 눌러야 할 곳은 카드마다 하나. 보조 동작(미리 듣기)만 따로 둔다.

## 방향

홍대 공연장 벽에 붙은 흑백 복사 전단지에서 가져온다. 강조색 없이 검정과 종이색만 쓴다. 거친 느낌은 바탕 질감과 망점에서 내고, 글자는 깔끔하게 둔다. 실제 포스터가 들어가면 색은 포스터가 가져온다.

## 색상

| 이름 | 값 | 사용처 |
| --- | --- | --- |
| `color-paper` | `#ECEBE7` | 화면 바탕 (회색 종이) |
| `color-card` | `#FAFAF8` | 카드, 정보 박스, 보조 버튼 바탕 (흰 종이) |
| `color-ink` | `#111111` | 글자, 테두리, 주요 행동(예매하기·선택된 칩·안내 보기) 채움 |
| `color-ink-sub` | `#4A4A4A` | 거리, 공연장, 확인 시각, 라벨 |
| `color-on-ink` | `#FFFFFF` | 검정 채움 위 글자 |

대비(기준 4.5:1): 검정 / 종이 15.8, 검정 / 카드 18.1, 보조 / 종이 7.4, 보조 / 카드 8.5, 흰 글자 / 검정 18.9.

색만으로 뜻을 전하지 않는다. 선택된 칩은 채움과 글자 굵기가 함께 달라지고, "처음 가기 좋음"은 도장 모양에 글자가 함께 있다.

## 질감

| 이름 | 값 | 사용처 |
| --- | --- | --- |
| `texture-grain` | 노이즈 타일 160px, 투명도 0.2, `multiply` | 화면 전체 위에 덮는 종이 질감. 클릭을 막지 않게 `pointer-events: none`. 목업은 SVG 필터지만, 구현에서는 저사양 폰 스크롤을 위해 미리 만든 PNG 타일을 쓴다 |
| `texture-halftone` | 6px 간격 옅은 망점(55%) + 밝은 회색 그라데이션 | 포스터 자리 표시 (목업 전용, 실제 내용처럼 보이지 않게 옅게) |
| `tape` | 52×18px 반투명 흰 조각, -5~5도 회전 | 포스터 칸 위쪽 장식. 보조 기술에서 숨긴다 |

질감은 글자 대비를 떨어뜨리지 않는 선에서만 쓴다. 글자 위에 회전이나 왜곡을 걸지 않는다(도장 배지의 -3도는 예외).

## 컴포넌트

### 공연 카드 (목록)

- 전체가 상세로 가는 링크 하나. 안에는 시작 시간, 도보 거리, 공연명, 공연장, 한 줄 설명, 배지, 현장가를 둔다.
- 포스터 있음: 왼쪽에 `104×144` 포스터 칸, 그 위 오른쪽 아래에 미리 듣기 버튼.
- 포스터 없음: 포스터 칸을 없애고 글자만 보여준다. 미리 듣기 버튼은 카드 오른쪽 아래.
- 포스터는 공연장이 올렸거나 사용을 허락한 경우에만 표시한다. 허락 전에는 글자 카드다.
- 배지는 카드당 하나. 가격은 배지 옆에 둔다.
- 한 시간 안에 시작하는 공연은 시간 위에 검정 채움 라벨로 "20분 뒤 시작"을 표시한다.
- "처음 가기 좋음"은 2px 테두리의 도장 모양(-3도)으로 표시한다.
- 포스터 자리 표시는 `texture-halftone`에 테이프를 붙이고, 왼쪽 아래에 "포스터" 라벨을 둔다.
- 공연명이 길면 줄바꿈하고(`overflow-wrap: anywhere`), 말줄임으로 자르지 않는다.

### 미리 듣기 버튼

- 목록: `44×44` 네모 버튼, 바탕 `color-card`에 2px 테두리, 검정 재생 삼각형, `aria-label="미리 듣기"`. 검정 채움은 쓰지 않는다.
- 상세: 글자 "미리 듣기"와 아이콘이 함께 있는 2px 테두리 버튼, 높이 48px.
- 상태: 기본 / 키보드 포커스 / 재생 중 / 불러오는 중 / 불러오기 실패("지금은 들을 수 없어요"). 재생 중에는 아이콘이 일시정지로 바뀐다.

### 칩 (필터)

- 높이 `44px`, 좌우 `14px`, 2px 테두리. 선택됨은 `color-ink` 채움 + 흰 글자 + 굵게, 선택 안 됨은 바탕 투명.
- `aria-pressed`로 선택 상태를 알리고, 칩 묶음에는 `role="group"`과 `aria-label`을 둔다. 폭이 모자라면 줄바꿈한다.

### 주요 버튼 / 보조 버튼

- 주요(예매하기, 빈 상태의 "내일 공연 보기"): 높이 `52px` 이상, 배경 `color-ink`, 흰 글자 16px 굵게. 한 화면에 하나만 둔다.
- 이동 버튼(공연 달력으로, 안내 보기): 높이 `56px`, 2px 테두리, 바탕 `color-card`, 오른쪽 화살표.
- 보조(길찾기): 높이 `52px`, 2px 테두리, 배경 `color-card`.
- 상태: 기본 / 키보드 포커스 / 비활성 / 진행 중. 진행 중에는 글자를 "여는 중"으로 바꾸고 중복 누름을 막는다.

### 검정 채움 규칙

- 검정 채움은 "지금 선택된 것"과 "화면의 주요 행동 하나"에만 쓴다: 선택된 탭·칩·날짜, 개수 강조, 곧 시작 라벨, 예매하기.
- 그 밖의 버튼은 테두리 버튼으로 둔다. 검정 채움이 많아지면 카드보다 버튼이 먼저 보인다.

### 걷는 거리 설정 (지금 근처)

- 기본값은 걸어서 15분. 제목 위 보조 글자 줄에 밑줄 글자 "걸어서 15분 안 ▾"로만 둔다. 따로 설정 버튼이나 칩을 만들지 않는다.
- 누르면 10·15·20·30분 중에서 고르고, 고른 값은 브라우저에 기억한다. 터치 영역은 44px을 지킨다.
- 공연 달력은 거리와 상관없이 전체 공연을 보여준다.

### 탭 (지금 근처 / 공연 달력)

- 머리말 아래 두 칸, 높이 `48px`, 2px 테두리. 현재 화면은 검정 채움과 `aria-current="page"`.
- 화면 이동이라 링크로 만든다.

### 공연 달력

- 주 단위 날짜 띠 7칸: 요일(오늘은 "오늘"), 날짜(`font-display` 22px), 그날 공연 수. 칸 높이 `76px`, 선택된 날은 검정 채움, `aria-label`에 날짜와 공연 수를 담는다.
- 띠 위에 월 이름, "오늘", 이전 주·다음 주 버튼(44px).
- 필터 칩: 전체 / 처음 가기 좋은 공연만.
- 날짜 아래 목록은 한 줄에 한 공연: 시간(`font-display` 20px) · 공연명 · 공연장 · 가격. 줄 높이 `64px` 이상, 줄 전체가 상세로 가는 링크. 포스터는 넣지 않는다.
- 이미 끝난 공연은 보조색 글자에 "끝남" 표시를 두고 목록 맨 위에 남긴다.

### 빈 상태와 위치를 모를 때

- 지금 갈 공연이 없으면 점선 박스에 "오늘 공연 끝"과 이유를 쓰고, 주요 버튼으로 다음 날 공연, 이동 버튼으로 공연 달력을 연다.
- QR(카페 코드) 없이 들어오면 "걸어서"라는 말을 쓰지 않는다. 제목은 "오늘 홍대 공연 N개", 거리 대신 동네 이름을 쓰고, "내 위치에서 걸어서 몇 분인지 보기" 버튼으로 위치 권한을 요청한다.

### 카드 상태

- 매진: "매진" 도장 + 가격에 취소선. 상세에서는 예매하기 대신 매진 표시.
- 현장 판매만: 가격 옆에 "현장에서만 팔아요". 상세에서 예매하기 버튼을 숨긴다.
- 이미 시작: 시간 위에 테두리 라벨 "N분 전에 시작했어요". 시작 30분이 지나면 지금 근처 목록에서 뺀다.

### 상세 화면 하단

- 길찾기·예매하기는 화면 아래 고정 바(`position: sticky; bottom: 0`)에 둔다. 위쪽에 2px 선, 바탕 `color-paper`.
- 고정 바가 포커스된 요소를 가리지 않게 `scroll-padding-bottom`을 바 높이만큼 준다.
- 정보 출처("출처: 공연장 인스타그램" + 원본 게시물 링크)를 고정 바 바로 위에 둔다. 원본 링크는 크롤링 정보를 믿을 수 있게 하는 장치라 빼지 않는다.
- "이 공연장의 다음 공연" 2개와 공연장 페이지 링크를 둔다.

### 길찾기 선택 시트

- 길찾기를 누르면 아래에서 올라온다. 제목 "어떤 지도로 볼까요?", 큰 버튼 세 개: 네이버지도 / 카카오맵 / 주소 복사.
- 처음 고른 지도는 브라우저에 저장하고, 다음부터는 시트 없이 바로 연다. 시트 아래의 "다른 지도로 보기"로 다시 고를 수 있다.
- 저장이 막혀 있으면 매번 시트를 보여준다.

### 설문 (처음/가끔/자주)

- `border-cut` 점선 영역 안에 선택지 세 개를 한 줄에 나란히, 높이 `48px`. 누르면 즉시 저장하고 "고마워요"로 바뀐다.

### 정보 확인 표시

- "정보가 다르면 알려주세요" 버튼(높이 44px)을 화면 아래에 둔다. 마지막 확인 시각은 화면에 표시하지 않는다. 글자 링크처럼 보여도 반드시 버튼으로 만든다.

## 접근성 기준

- 본문 16px 이상, 보조 글자 14px 이상, 눌러야 하는 곳 44px 이상.
- 키보드 포커스는 `3px` 윤곽선(`color-ink`)에 `2px` 간격으로 항상 보이게 한다.
- 움직임은 `prefers-reduced-motion`을 따르고, 움직이는 요소가 없어도 같은 정보를 읽을 수 있어야 한다.
- 화면 아래에 고정하는 버튼은 포커스된 요소를 가리지 않게 `scroll-padding`을 둔다.
- 비동기로 채워지는 영역은 자리를 미리 잡아 화면이 밀리지 않게 한다(포스터 칸 크기 고정).
- 모든 버튼은 키보드로 접근할 수 있고 포커스가 보여야 한다.
- 이미지와 아이콘 버튼에는 `aria-label` 또는 대체 텍스트를 둔다. 포스터 이미지의 대체 텍스트는 "공연명 · 공연장 포스터" 형식.
- 장식용 포스터 자리 표시는 보조 기술에서 숨긴다.
