# 홍대플로우 디자인 시스템

실제 목업(`홍대플로우 모바일 목업`)에서 쓰는 값을 기록한다. 값이나 사용처를 바꿀 때 코드와 이 문서를 함께 고친다.
원칙: [디자인 원칙](https://github.com/sngmng6506/Oh-My-System/blob/main/DESIGN_PRINCIPLES.md)

## 기준

- 모바일 우선, 화면 폭 390px 기준. 넓은 화면에서는 목록을 2~3열로 늘린다.
- 본문은 쉬운 말로 쓴다. 전문 용어 대신 "서서 보는 공연", "기타 한 대로 부르는 잔잔한 노래"처럼 쓴다. 근거를 댈 수 없는 추천 표시("처음 가기 좋음" 같은)는 붙이지 않는다.
- 눌러야 할 곳은 카드마다 하나. 보조 동작(미리 듣기)만 따로 둔다.

## 방향

홍대 공연장 벽에 붙은 흑백 복사 전단지에서 가져온다. 강조색 없이 검정과 종이색만 쓴다. 거친 느낌은 바탕 질감과 망점에서 내고, 글자는 깔끔하게 둔다. 실제 포스터가 들어가면 색은 포스터가 가져온다.

## 색상

| 이름 | 값 | 사용처 |
| --- | --- | --- |
| `color-paper` | `#ECEBE7` | 화면 바탕 (회색 종이) |
| `color-card` | `#FAFAF8` | 카드, 정보 박스, 보조 버튼 바탕 (흰 종이) |
| `color-ink` | `#111111` | 글자, 테두리, 주요 행동(예매하기·선택된 칩·안내 보기) 채움 |
| `color-ink-sub` | `#4A4A4A` | 거리, 공연장, 확인 시각, 라벨 |
| `color-on-ink` | `#FFFFFF` | 검정 채움 위 글자 |

대비(기준 4.5:1): 검정 / 종이 15.8, 검정 / 카드 18.1, 보조 / 종이 7.4, 보조 / 카드 8.5, 흰 글자 / 검정 18.9.

색만으로 뜻을 전하지 않는다. 선택된 칩은 채움과 글자 굵기가 함께 달라지고, "매진"은 도장 모양에 글자가 함께 있다.

## 질감

| 이름 | 값 | 사용처 |
| --- | --- | --- |
| `texture-grain` | 노이즈 타일 160px, 투명도 0.2, `multiply` | 화면 전체 위에 덮는 종이 질감. 클릭을 막지 않게 `pointer-events: none`. 목업은 SVG 필터지만, 구현에서는 저사양 폰 스크롤을 위해 미리 만든 PNG 타일을 쓴다 |
| `texture-halftone` | 6px 간격 옅은 망점(55%) + 밝은 회색 그라데이션 | 포스터 자리 표시 (목업 전용, 실제 내용처럼 보이지 않게 옅게) |
| `tape` | 52×18px 반투명 흰 조각, -5~5도 회전 | 포스터 칸 위쪽 장식. 보조 기술에서 숨긴다 |

질감은 글자 대비를 떨어뜨리지 않는 선에서만 쓴다. 글자 위에 회전이나 왜곡을 걸지 않는다(도장 배지의 -3도는 예외).

## 화면 구성

화면은 공연 목록과 공연 상세 두 장이다. 탭, 필터 칩, 설문, 안내 버튼, 공연장 페이지는 두지 않는다.

## 컴포넌트

### 상자 규칙

- 2px 테두리 상자는 공연 카드와 상세의 시간·가격 칸에만 쓴다. 나머지 구역은 2px 가로선으로 나눈다.
- 검정 채움은 "지금 선택된 것"(날짜, 걷는 시간)과 개수 강조, 곧 시작 라벨, 예매하기에만 쓴다.
- 근거를 댈 수 없는 추천 표시는 붙이지 않는다.

### 날짜 띠 (목록)

- 머리말 아래 7칸: 요일(오늘은 "오늘"), 날짜(`font-display` 22px), 그날 공연 수("6개"처럼 단위를 붙인다).
- 칸 높이 `80px`, 테두리 없이 아래 2px 선 하나. 선택된 날만 검정 채움. `aria-label`에 날짜와 공연 수를 담는다.
- 옆으로 밀어 2주 뒤까지 본다. 이전·다음 버튼은 두지 않는다.
- 날짜 띠의 공연 수는 거리와 상관없는 그날 전체 공연 수다.

### 출발 위치와 걷는 시간

- 목록은 기본으로 출발 위치에서 걸어서 15분 안의 공연만 보여준다. 제목은 "오늘 걸어갈 수 있는 공연 N개".
- 출발 위치는 다음 순서로 정한다.
  1. QR로 들어왔으면 그 카페
  2. 사용자가 위치 사용을 허락했고 위치가 홍대 일대 안이면 내 위치
  3. 그 밖에는 홍대입구역 (위치를 못 쓰거나, 거절했거나, 홍대 일대 밖에 있을 때)
- 제목 아래 밑줄 글자 한 줄로만 보여준다: "홍대입구역에서 걸어서 15분 안 ▾". 누르면 시트가 올라온다.
- 위치를 아직 허락하지 않았으면 같은 줄 오른쪽에 "내 위치로"를 둔다. 위치 권한은 이것을 눌렀을 때만 묻고, 허락하면 다음부터는 묻지 않고 내 위치를 쓴다. 허락한 뒤에는 이 글자를 숨긴다.
- 시트: 출발 위치(카페 / 내 위치 / 홍대입구역), 걷는 시간(10·15·20·30분), "거리 상관없이 전체 보기". 고르면 바로 적용하고 브라우저에 기억한다.
- 목록 끝에 "더 먼 공연 N개도 보기"를 둔다. 걸어갈 수 있는 공연이 없으면 같은 자리에서 그날 전체 공연과 다음 날로 안내한다.

### 공연 카드 (목록)

- 카드 전체가 상세로 가는 링크 하나다. 안에는 시작 시간(`font-display` 26px), 도보 시간, 공연명, 공연장, 가격을 둔다. 카드 안에 다른 버튼은 두지 않는다.
- 한 줄 설명은 출처가 있을 때만 넣는다(아티스트 소개 글 등). 없으면 비운다. 듣지 않은 음악을 지어내 쓰지 않는다.
- 한 시간 안에 시작하는 공연은 시간 위에 검정 채움 라벨로 "20분 뒤 시작"을 표시한다.
- 글자 카드가 기본이다. 허락된 포스터가 있을 때만 왼쪽에 `72×100` 포스터를 둔다.
- 이미 끝난 공연은 목록에서 뺀다. 매진·현장 판매 같은 상태 표시는 수동 운영으로 유지할 수 없어 두지 않는다.
- 공연명이 길면 줄바꿈하고(`overflow-wrap: anywhere`), 말줄임으로 자르지 않는다.

### 공연 상세

- 위에서부터: 목록으로 돌아가기, 날짜·공연명·공연장, 시작 시간과 현장 가격 칸, 출연, 찾아가는 길, 출처.
- 출연: 팀 이름, 출처가 있는 한 줄 설명, "유튜브에서 들어보기" 바깥 링크. 링크가 없으면 줄을 숨긴다. 앱 안에서 재생되는 것처럼 보이는 재생 버튼은 쓰지 않는다.
- 출처: "출처: 공연장 인스타그램"과 원본 게시물 링크. 크롤링 정보를 믿을 수 있게 하는 장치라 빼지 않는다.
- 길찾기·예매하기는 화면 아래 고정 바(`position: sticky; bottom: 0`)에 둔다. 예매 링크가 없으면 길찾기만 둔다. 고정 바가 포커스된 요소를 가리지 않게 `scroll-padding-bottom`을 준다.

### 주요 버튼 / 보조 버튼 / 글자 버튼

- 주요(예매하기): 높이 `52px`, 배경 `color-ink`, 흰 글자 16px 굵게. 한 화면에 하나만 둔다.
- 보조(길찾기): 높이 `52px`, 2px 테두리, 배경 `color-card`.
- 글자 버튼(출발 위치, 더 보기, 수정요청): 밑줄 글자, 터치 영역 `44px` 이상. 글자 링크처럼 보여도 반드시 버튼으로 만든다.
- 상태: 기본 / 키보드 포커스 / 비활성 / 진행 중.

### 길찾기 선택 시트

- 길찾기를 누르면 아래에서 올라온다. 네이버지도 / 카카오맵 / 주소 복사.
- 처음 고른 지도는 브라우저에 저장하고, 다음부터는 시트 없이 바로 연다.

### 수정요청

- "정보가 다르면 알려주세요" 글자 버튼을 목록과 상세 아래에 둔다. 마지막 확인 시각은 화면에 표시하지 않는다.

## 접근성 기준

- 본문 16px 이상, 보조 글자 14px 이상, 눌러야 하는 곳 44px 이상.
- 키보드 포커스는 `3px` 윤곽선(`color-ink`)에 `2px` 간격으로 항상 보이게 한다.
- 움직임은 `prefers-reduced-motion`을 따르고, 움직이는 요소가 없어도 같은 정보를 읽을 수 있어야 한다.
- 화면 아래에 고정하는 버튼은 포커스된 요소를 가리지 않게 `scroll-padding`을 둔다.
- 비동기로 채워지는 영역은 자리를 미리 잡아 화면이 밀리지 않게 한다(포스터 칸 크기 고정).
- 모든 버튼은 키보드로 접근할 수 있고 포커스가 보여야 한다.
- 이미지와 아이콘 버튼에는 `aria-label` 또는 대체 텍스트를 둔다. 포스터 이미지의 대체 텍스트는 "공연명 · 공연장 포스터" 형식.
- 장식용 포스터 자리 표시는 보조 기술에서 숨긴다.
