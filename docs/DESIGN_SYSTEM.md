# 홍대플로우 디자인 시스템

실제 목업(`홍대플로우 모바일 목업`)에서 쓰는 값을 기록한다. 값이나 사용처를 바꿀 때 코드와 이 문서를 함께 고친다.
원칙: [디자인 원칙](https://github.com/sngmng6506/Oh-My-System/blob/main/DESIGN_PRINCIPLES.md)

## 기준

- 모바일 우선, 화면 폭 390px 기준. 넓은 화면에서는 목록을 2~3열로 늘린다.
- 본문은 쉬운 말로 쓴다. 전문 용어 대신 "서서 보는 공연", "처음 가기 좋음"처럼 쓴다.
- 눌러야 할 곳은 카드마다 하나. 보조 동작(미리 듣기)만 따로 둔다.

## 색상

| 이름 | 값 | 사용처 |
| --- | --- | --- |
| `color-bg` | `#FAF7F2` | 화면 배경 |
| `color-surface` | `#FFFFFF` | 카드, 정보 박스 |
| `color-surface-muted` | `#EFE8DC` | 선택하지 않은 칩, 보조 버튼 배경 |
| `color-border` | `#E8DFD0` | 카드 테두리 (1px 그림자 선) |
| `color-text` | `#1F1B16` | 본문, 제목 |
| `color-text-soft` | `#3D362E` | 한 줄 설명, 카드 안 본문 |
| `color-text-sub` | `#5E564C` | 거리, 확인 시각, 보조 설명 |
| `color-accent` | `#C8321A` | 주요 행동(예매하기), 선택된 칩, 강조 숫자 |
| `color-success-bg` | `#E3F1E8` | "처음 가기 좋음" 배지와 안내 박스 배경 |
| `color-success-text` | `#1E6B4A` | "처음 가기 좋음" 글자와 안내 박스 제목 |
| `color-success-line` | `#CFE3D6` | 안내 박스 안의 구분선 |
| `color-poster-1~4` | `#E7D9C3` `#D9E2D0` `#EBD3CE` `#D6DCE8` | 포스터 자리 표시 (실제 포스터가 없을 때만) |

대비(글자색 / 배경색, 기준 4.5:1): 본문 16.0, 보조 6.8, 배지 5.5, 흰 글자 / 강조색 5.4, 강조색 글자 / 배경 5.0, 포스터 칸 위 보조 글자 5.2. 강조색을 바꿀 때는 흰 글자 대비 4.5 이상인지 먼저 확인한다.

색만으로 뜻을 전하지 않는다. "처음 가기 좋음"은 글자가 함께 있고, 선택된 칩은 색과 글자 굵기가 함께 달라진다.

## 글꼴

글꼴은 `Noto Sans KR` (400 / 500 / 700), 대체 글꼴은 시스템 기본.

| 이름 | 값 | 사용처 |
| --- | --- | --- |
| `font-hero` | `26px / 1.3 / 700` | 목록 화면 첫 문장 |
| `font-title` | `24px / 1.3 / 700` | 상세 화면 공연명 |
| `font-time` | `22px / 700` | 카드의 시작 시간, 로고 |
| `font-card-title` | `17px / 1.35 / 700` | 카드의 공연명 |
| `font-body` | `16px / 1.5` | 본문, 버튼 |
| `font-desc` | `16px` | 카드 한 줄 설명, 안내 내용 |
| `font-caption` | `14px` | 거리, 공연장, 확인 시각, 배지, 라벨 |

본문과 안내 글은 16px 이상, 가장 작은 글자는 14px이다. 13px 이하는 쓰지 않는다.

## 컴포넌트

### 공연 카드 (목록)

- 전체가 상세로 가는 링크 하나. 안에는 시작 시간, 도보 거리, 공연명, 공연장, 한 줄 설명, 배지, 현장가를 둔다.
- 포스터 있음: 왼쪽에 `104×144` 포스터 칸, 그 위 오른쪽 아래에 미리 듣기 버튼.
- 포스터 없음: 포스터 칸을 없애고 글자만 보여준다. 미리 듣기 버튼은 카드 오른쪽 아래.
- 포스터는 공연장이 올렸거나 사용을 허락한 경우에만 표시한다. 허락 전에는 글자 카드다.
- 배지는 카드당 하나. 가격은 배지 옆에 둔다.
- 한 시간 안에 시작하는 공연은 시작 시간 옆에 `color-accent`로 "20분 뒤 시작"을 표시한다.
- 공연명이 길면 줄바꿈하고(`overflow-wrap: anywhere`), 말줄임으로 자르지 않는다.

### 미리 듣기 버튼

- 목록: `44×44` 둥근 버튼, 배경 `color-text`, 아이콘 재생 삼각형, `aria-label="미리 듣기"`.
- 상세: 글자 "미리 듣기"와 아이콘이 함께 있는 윤곽선 버튼, 높이 48px.
- 상태: 기본 / 키보드 포커스 / 재생 중 / 불러오는 중 / 불러오기 실패("지금은 들을 수 없어요"). 재생 중에는 아이콘이 일시정지로 바뀐다.

### 칩 (필터)

- 높이 `44px`, 좌우 `16px`, 선택됨은 `color-accent` 배경 + 흰 글자 + 굵게, 선택 안 됨은 `color-surface-muted`.
- `aria-pressed`로 선택 상태를 알리고, 칩 묶음에는 `role="group"`과 `aria-label`을 둔다. 폭이 모자라면 줄바꿈한다.

### 주요 버튼 / 보조 버튼

- 주요(예매하기): 높이 `52px`, 배경 `color-accent`, 흰 글자 16px 굵게.
- 보조(길찾기): 높이 `52px`, 1.5px 윤곽선, 배경 투명.
- 상태: 기본 / 키보드 포커스 / 비활성 / 진행 중. 진행 중에는 글자를 "여는 중"으로 바꾸고 중복 누름을 막는다.

### 길찾기 선택 시트

- 길찾기를 누르면 아래에서 올라온다. 제목 "어떤 지도로 볼까요?", 큰 버튼 세 개: 네이버지도 / 카카오맵 / 주소 복사.
- 처음 고른 지도는 브라우저에 저장하고, 다음부터는 시트 없이 바로 연다. 시트 아래의 "다른 지도로 보기"로 다시 고를 수 있다.
- 저장이 막혀 있으면 매번 시트를 보여준다.

### 처음 가는 분께 박스 (상세)

- 배경 `color-success-bg`, 제목 `color-success-text`, 줄마다 라벨(84px 고정)과 내용. 항목: 입구 / 입장 / 자리 / 음료 / 혼자 가도.
- 공연장이 확인한 내용만 채운다. 비어 있으면 그 줄은 보이지 않게 한다.

### 설문 (처음/가끔/자주)

- 선택지 세 개를 한 줄에 나란히, 높이 `48px`. 누르면 즉시 저장하고 "고마워요"로 바뀐다.

## 접근성 기준

- 본문 16px 이상, 보조 글자 14px 이상, 눌러야 하는 곳 44px 이상.
- 키보드 포커스는 `3px` 윤곽선(`color-text`)에 `2px` 간격으로 항상 보이게 한다.
- 움직임은 `prefers-reduced-motion`을 따르고, 움직이는 요소가 없어도 같은 정보를 읽을 수 있어야 한다.
- 화면 아래에 고정하는 버튼은 포커스된 요소를 가리지 않게 `scroll-padding`을 둔다.
- 비동기로 채워지는 영역은 자리를 미리 잡아 화면이 밀리지 않게 한다(포스터 칸 크기 고정).
- 모든 버튼은 키보드로 접근할 수 있고 포커스가 보여야 한다.
- 이미지와 아이콘 버튼에는 `aria-label` 또는 대체 텍스트를 둔다. 포스터 이미지의 대체 텍스트는 "공연명 · 공연장 포스터" 형식.
- 장식용 포스터 자리 표시는 보조 기술에서 숨긴다.
