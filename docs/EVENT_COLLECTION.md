# 공연 정보 수집 — Instagram API 없이

## 구현 범위

- 공식 공연장 페이지에서 공개 JSON-LD `MusicEvent` 또는 `Event` 구조화 데이터를 탐색
- 롤링홀과 언플러그드 홍대 출처별 URL 및 공연장 매핑
- 공연명·명시적 타임존이 있는 시작시각·공식 출처·라인업·공개 가격·예매 링크 추출
- HTTPS URL만 허용, 타 공연장 이벤트 배제, 공연장/시작시간/제목 기준 중복 제거
- 12초 요청 제한, 1MB 문서 제한, 수집 보고서 생성
- **자동 게시하지 않음**: 기존 `/admin/import`로 검수 대기(pending) 등록

## 사용

```bash
npm ci
npm run collect:events
```

`data/collection-report.json`에 결과와 수집 실패 이유가 남습니다. 실제 등록용 JSON을 만들려면 관리자 대시보드에서 공연장 ID를 확인하고 `data/venue-ids.json`을 작성합니다.

```json
{
  "언플러그드 홍대": 1,
  "롤링홀": 2
}
```

**숫자는 예시입니다. 실제 DB의 ID로 바꾸세요.**

```bash
npm run collect:export
```

생성된 `data/collected-events.json`을 `/admin/import`에서 가져옵니다. 수집 결과가 100건을 넘으면 100건 이하 배열로 분할하세요.

특정 출처만 실행하려면 `npm run collect:events -- --source unplugged` 또는 `--source rollinghall`을 사용합니다.

## 제한 및 안전장치

- 공개 페이지에 구조화된 이벤트가 없거나 타임존이 명시되지 않으면 **0건**으로 보고합니다. 날짜나 시간을 추측해 공연을 생성하지 않습니다.
- 롤링홀의 공식 페이지는 일정 텍스트를 제공하지만, JSON-LD가 없다면 이 버전의 수집기는 공연을 가져오지 않습니다. HTML 구조가 불안정한 사이트별 파서는 검증 후 추가해야 합니다.
- 언플러그드의 일부 페이지는 표시 날짜/시각과 본문 공지의 날짜/시각이 다를 수 있습니다. 출처 충돌 시 자동 확정하지 말고 수동 검수해야 합니다.
- 자동 우회, 로그인 우회, Instagram 비공식 스크래핑, 대량 수집은 하지 않습니다. robots.txt 및 서비스 이용약관을 확인하고 수집 허용 범위에서만 실행하세요.
- 포스터는 저작권·사용 허락을 확인하기 전에는 자동 복제하지 않습니다.
- 실제 실행 결과와 수집 성공 건수는 배포 환경에서 확인해야 합니다. 코드가 추가되었다고 수집 성공을 의미하지 않습니다.
